# DeckBeacon for Decky Loader

The optional Decky Loader plugin for DeckBeacon (pairing, agent status and notifications inside Gaming Mode).

**Not released yet.** The plugin is planned for milestone M4. This repository will hold the generated plugin (at the root, for the Decky plugin store), built from the [DeckBeacon monorepo](https://github.com/Jafesu/DeckBeacon).
